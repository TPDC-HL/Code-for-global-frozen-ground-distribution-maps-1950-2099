# Data availability — preliminary

Research-source climate, CALM and satellite data should be obtained through and cited to their original repositories. No private field monitoring or triboelectrification measurements are included in this code repository.

Original electric-field and laboratory triboelectrification data were not provided for this code release; the field-data release requires rights clearance, documented site metadata and resolution of sensor-date discrepancies. No data DOI has been issued. Do not describe unpublished source files as publicly archived.
